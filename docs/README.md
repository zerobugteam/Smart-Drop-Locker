3. [03-rencana-dan-riwayat-migrasi.md](./03-rencana-dan-riwayat-migrasi.md) — Peta migrasi file lama ke struktur Express, daftar perubahan yang telah diimplementasikan, hasil verifikasi teknis, dan backlog langkah selanjutnya.
